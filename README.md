# ConfiCel

ConfiCel turns document workflows into structured, reviewable data.

## Preserved checkpoints
- `01-initial-website` — initial website
- `02-brand-visual-update` — brand visual update
- `03-hero-token-cleanup` — hero and token concept cleanup
- `04-workspace-foundation` — workspace UI and conversion-engine plan
- `05-conversion-engine` — Python API foundation for OCR drafts and XLSX export

See `docs/05-conversion-engine-implementation.md` and `backend/README.md` for capabilities and limitations. The current public Pages site remains a demo until the API is separately deployed and connected. Do not upload confidential documents to the demo.
